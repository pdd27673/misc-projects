How this works

Searches run server-side in a Cloudflare Pages Function, which fetches CSUN's Class Search and reads the section list out of the page. The parser matches on column headings rather than CSS selectors, so a schedule redesign does not silently break it.

Schedule building happens in your browser over the sections you have already loaded — it enumerates every conflict-free combination and ranks them by fewest days on campus.

Seat counts are as accurate as the moment the page was fetched. Always confirm in the official Class Search before you register.
